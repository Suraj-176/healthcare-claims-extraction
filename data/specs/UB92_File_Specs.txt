Introduction

This document provides the format and data contents of the UB-92 health care claim transactions for claim submission to United HealthCare Corporation. The data elements and design of the records are based on the National Uniform Billing Committee. UnitedHealthcare uses this UB-92 format as the basis for its electronic UB-92 claim submission.

This document describes in detail each record type used in a UB-92 claim. The first part of the record type description provides record level information, the record type code and name, comments about the record's physical placement in the transaction file and details about when the record type is required, conditional, optional or not used. This is followed by information about each field in the record type. Each field contains the following information:

Field No.	A unique number assigned to each field within the record type to assist in field identification.

Positions	From Position - Identifies the first or starting position of the field within 	the record layout.
	To Position - Identifies the last or ending position of the field within the 	 record layout.

Picture	The COBOL programming value assigned to each data element. Following is a list of the different picture clauses that may appear in the specifications:
			PIC X(n) - alpha/numeric characters
			PIC 9(n) - numeric characters
			PIC 9(n)V99 - numeric, dollar amount, decimal implied
			PIC S9(n)V99 - signed, numeric, dollar amount, decimal implied
			
			All alpha/numeric fields must be left justified, space filled.
			All numeric fields must be right justified, zero filled.
			All alpha/numeric fields must be initialized to spaces.
			All numeric fields must be initialized to zeros.

Req Field	Indicates the requirement for the field. There are six possible values which are the following:
	R    	indicates that the field is required on both inpatient and outpatient claims.
	RI	indicates that the field is required for inpatient claims only.
	RO	indicates that the field is required for outpatient claims only.
 	O	indicates that the field is optional.
	C	indicates that the field is conditional. The condition for its presence is identified in the field name/description column.
	N	indicates that the field is not used.

	Refer to Exhibit # 3 Batch and Bill Type Codes for definitions of inpatient and outpatient claims.

Field Name/Description - Provides a concise definition of the data contained in the field and any special codes or rules for its valid values. 
Figure 1 below shows the structure of the UB-92 transaction file. The hierarchical structure and relationship between the various records of the UB-92 transaction file is denoted by the indentation of the record type codes.

A batch consists of Record Type 10 through and including record type 95.  There can be multiple batches in one transaction file. 

A claim consists of Record Type 20 through and including record type 91.  There can be multiple claims in one batch.

Exhibit # 5
Occurrence Codes 

Occurrence Codes and Occurrence Span Codes are mutually exclusive. Occurrence Code values are 01 - 69 and A1 - L9.  Occurrence Span Code values are 70 - 99 and M0-Z9. Occurrence Codes require a date; while Occurrence Span Codes require a FROM and THRU date. 

Record Type 40 holds seven (7) Occurrence Code fields and two (2) Occurrence Span Code fields. Occurrence Span Codes may be passed in the Occurrence Code fields if there are more than two (2) to report. Likewise, Occurrence Codes may be passed in the Occurrence Span Code fields if there are more than seven (7) to report.

When an Occurrence Code & date is passed in the Occurrence Span Code fields, the Thru Date is not required. Likewise, when an Occurrence Span Code is passed in the Occurrence Code fields, two (2) occurrences of Occurrence Code/Date are used. The Occurrence Span Code is passed in  the first Occurrence Code field, the from date is passed in the first Occurrence Date field, the Occurrence Span Code (equal to the previous) is passed in the next occurrence of Occurrence Code and the Thru Date is passed in the Occurrence Date field.  

	Accident Related Codes
